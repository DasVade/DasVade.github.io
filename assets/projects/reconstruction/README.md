On 2026-10-24 the owner explicitly confirmed having obtained permission to
publish these visuals, after review of the source repository's unresolved
publication note. This confirmation applies to selected display visuals,
not general release of course solutions, input datasets, weights or archives.

framework and inputs; TempleRing is the Middlebury MVS dataset. The project
page distinguishes experimental extensions and legacy diagnostic imagery.

The sweep is a historical supplied-checkpoint 50×50 render over eight supplied
poses, including training views. It is not the fresh model's six-view 100×100
test benchmark. Frames, blur and original GIF timing are preserved.
